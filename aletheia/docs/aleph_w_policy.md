# Política de Uso de Aleph_w

- Preferir Aleph_w para grafos, contenedores y algoritmos en C++ cuando sea práctico.
- No inventar nombres de APIs.
- No asumir headers, clases, funciones ni namespaces.
- Inspeccionar headers/ejemplos locales en Fase 9+ antes de integrar.
- Usar wrappers pequeños y llamar desde Ruby vía JSON, CSV o SQLite.
- Mantener los algoritmos de C++ estrictamente separados de las credenciales de Binance.
