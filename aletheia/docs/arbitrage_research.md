# Investigación de Arbitraje

El análisis de arbitraje será teórico por defecto (Fase 9+).
Para cualquier oportunidad aparente se debe evaluar:
- bid/ask direction
- fees
- spread
- slippage
- order book depth
- lot size
- tick size
- minimum notional
- latency
- partial fills
- API failure

Reportar falsos positivos claramente. No operar.
